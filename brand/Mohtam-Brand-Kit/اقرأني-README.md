# هوية مهتم: حزمة الهوية الكاملة

**مهتم**، حوّل الاهتمام إلى فرصة.
إدارة العملاء المحتملين، التأهيل والمتابعة في مكان واحد.

**مراحل العميل:** وصل ← تواصل ← تأهّل ← موعد ← صفقة

**المميزات:**
- حملاتك على كل المنصات في شاشة واحدة
- تواصل آلي مع كل عميل خلال دقائق من وصوله
- كل صفقة تعود إلى الحملة التي جاءت بها

---

## محتويات الحزمة

| المجلد | المحتوى |
|---|---|
| `01-الشعار-Logo` | الشعار بخمس صيغ لونية، وكل صيغة بخمسة أشكال: أفقي، وعمودي، وعمودي مع الجملة، والرمز فقط، والاسم فقط. الملفات بصيغ SVG و PNG، ومعها JPG للمعاينة |
| `02-الأيقونات-Favicon-App` | أيقونات المتصفح (favicon.ico و favicon.svg)، وأيقونات آيفون وأندرويد، وملف site.webmanifest، وأسطر head-snippet.html، وأيقونة تطبيق 1024 بثلاث خلفيات |
| `03-سوشل-ميديا-Social` | الأفاتار، والأغلفة والهيدر لكل منصة، وأغلفة الهايلايت، وقوالب المنشورات والستوري، كلها بنسختين: غامقة `dark` وفاتحة `light` |
| `04-دليل-الهوية-Brand-Guide` | دليل الهوية بصيغة PDF، وصفحاته كصور |
| `05-الألوان-Colors` | ملفات الألوان للكود: CSS للوضعين، و Tailwind، و JSON، وملف نصي فيه أكواد HEX و RGB و CMYK |
| `06-الخطوط-Fonts` | خط IBM Plex Sans Arabic من Light إلى Bold، مع ملف الترخيص |
| `07-المطبوعات-Stationery` | بطاقة عمل بوجهين، وورق رسمي A4، وتوقيع إيميل |

## صيغ الشعار

| الصيغة | الألوان | متى تستخدمها |
|---|---|---|
| `primary` | حلقة زمردية، ونقطة نحاسية، واسم صنوبري | الأساسية، على الخلفيات الفاتحة |
| `reverse` | حلقة واسم بلون جيري فاتح، ونقطة نحاسية | على الخلفية الصنوبرية الغامقة |
| `on-green` | أبيض، ونقطة نحاسية فاتحة | على الخلفية الزمردية في العروض والإعلانات |
| `mono-black` | أسود فقط | الطباعة بلون واحد والأختام |
| `mono-white` | أبيض فقط | فوق الصور |

## الألوان

| اللون | HEX | الاستخدام |
|---|---|---|
| صنوبري 900 | `#0C2A25` | الخلفيات الغامقة، والقائمة الجانبية، واسم الشعار |
| زمردي 700 (الأساسي) | `#1D5E52` | الأزرار، والروابط، وحلقة الشعار |
| نحاسي 500 | `#B38A55` | نقطة الشعار، والأرقام المهمة. لا يزيد عن 5% من أي شاشة |
| نحاسي 400 | `#C9A26E` | النقطة والتمييز على الخلفيات الغامقة |
| نحاسي 700 | `#84612F` | النصوص المميزة على الخلفيات الفاتحة |
| حجري | `#E9E1D4` | الأقسام والمطبوعات |
| جيري | `#F6F3EE` | الخلفية العامة |
| حبر / رمادي | `#14201D` / `#5B6662` | النصوص |
| ألوان الحالة | `#2F7D5B` `#C08A2E` `#9E3B30` `#3A6F95` | سليم، وتنبيه، وخطر، ومعلومة. داخل النظام فقط |

**توزيع الألوان في أي تصميم:** 60% جيري، و25% أخضر، و10% حجري، و5% نحاسي كحد أقصى.

**في الكود:** ملف `mohtam-colors.css` يعطيك الوضع الفاتح افتراضيًا. للوضع الغامق ضِف `data-theme="dark"` أو الكلاس `theme-dark`.

## الخط

الهوية كلها بخط واحد: **IBM Plex Sans Arabic**، وهو نفس خط الشعار، ومجاني.

```html
<link href="https://fonts.googleapis.com/css2?family=IBM+Plex+Sans+Arabic:wght@300;400;500;600;700&display=swap" rel="stylesheet">
```

## تركيب الأيقونات في النظام

انسخ محتويات `02-الأيقونات-Favicon-App` إلى مجلد `public`، وحط أسطر `head-snippet.html` داخل `<head>`.

## قواعد الاستخدام

- **المسافة الآمنة:** اترك حول الشعار فراغ لا يقل عن ضعف قطر النقطة.
- **أصغر مقاس:** 96px للشعار الأفقي، و20px للرمز لحاله.
- **ممنوع:**
  - تلوين الحلقة بالنحاسي، أو أي ألوان خارج الصيغ الخمس.
  - إضافة ظلال أو تدرجات.
  - تغيير خط الاسم أو مطّه.
- **الطباعة:** أكواد CMYK تقريبية، فاطلب بروفة من المطبعة قبل الطباعة الكبيرة.
